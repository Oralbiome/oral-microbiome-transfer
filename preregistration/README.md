# Revised analysis plan (v2) for the Oralbiome reanalysis

This folder holds the revised analysis plan for the OSF registration https://osf.io/6k82q/ (DOI 10.17605/OSF.IO/6K82Q), "Presence-aware reanalysis of oral-microbiome diabetes-status transfer and NHANES incremental value".

- **File:** `PREREGISTRATION_REANALYSIS_v2.md`
- **SHA-256 of the revised plan:** `9693886a3ca7f9ba842e777ace16f66fa9dcfd56893264e9cd0c9264020e21b3`
- **Status:** the plan takes effect when OSF Update 2 is approved. The Update quotes the SHA-256 above. Until then the originally registered plan stays in force. The full analysis stays blocked until the synthetic qualification and a new sample on permuted or synthetic labels pass and the owner approves the run.
- **Originally registered plan:** SHA-256 `43c450568f510fa8427e4b3fae06ca7fb3edf7771d6a83a349cbd338a8716e24`. That plan is archived on OSF with the registration.
- **Contents:** the plan text only. It contains aggregate statistics (for example AUCs) and design rules. It contains no data and no participant-level information.

To check the file, hash it (for example `shasum -a 256 PREREGISTRATION_REANALYSIS_v2.md`) and compare with the value above and with the value quoted in OSF Update 2.
