## Scope and criteria written before checks

This is a documentary and aggregate-consistency check, not a new hypothesis test.
No participant data, network calls, fitting, outcome scoring, or full numerical
reconstruction is required. Original numerical sources and reports stay frozen.

| Criterion | Passing observation | Failure means |
|---|---|---|
| Evidence identity | Every ledger evidence file matches its recorded SHA-256 | Evidence changed or is missing; stop |
| Claim traceability | Every correction names evidence, mechanism, correction, supported conclusion and remaining limit | Audit claim is incomplete; stop |
| Aggregate agreement | Exact counts and unrounded estimates match named fields in retained JSON | Claim/artifact disagreement; stop |
| Discrimination | Correct synthetic evidence passes; wrong number, changed bytes, missing field/file and unsupported claim scope each fail | Checker cannot discriminate; do not trust it |
| Delivery | Run the same checker against both checkout and extracted package, including Python without site packages | A helper outside the delivered package may be supplying evidence |
| Scope preservation | Frozen analysis/report hashes and existing manuscript result-block numbers match the prior receipt | Revision changed numerical research; investigate before proceeding |

The ledger distinguishes documentary findings from aggregate consistency.
Matching a hash does not independently prove specimen identity, clinical truth,
consent, participant independence, or scientific validity. Current synthetic
analysis controls check selected functions; they do not replace a complete rerun.

Its reusable output is an ordered verification procedure, not a newly validated
algorithm or evidence that these errors occur at a particular rate elsewhere.
