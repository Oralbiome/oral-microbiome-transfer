## Repository metadata file

`commandem.toml` at the repository root is an intentionally empty roadmap stub
("no private roadmap history"). The unmodified archived script
`studies/cross-population-t2d/scripts/build_site_data.py` reads a root-level

code as private. That wording predates the release: the paper, the 59-file code
archive and this repository are public; only the original research repository
and its Git/LFS history are private. See the dated erratum in
